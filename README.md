# Граф зависимостей Python-пакетов, вариант 4

Практическая работа № 2. ИКБО-62-25. Автор: xyezipster.
Этап 4: прямой граф и поиск обратных зависимостей.

Нужен Python 3.11+. Установка библиотек и сборка не требуются.
Запуск из папки проекта:

```sh
python3 -B main.py
python3 -B main.py --config configs/requests.toml
python3 -B -m unittest discover -s tests -v
```

В PyCharm можно открыть `main.py` и нажать Run.

## Настройки

```toml
package = "A"
repository = "data/demo.json"
test_mode = true
```

`package` задаёт имя пакета. `repository` содержит URL репозитория
или путь к тестовому JSON относительно TOML-файла. `test_mode`
переключает тестовый и реальный режимы. В тестовом режиме имена состоят
из больших букв A–Z. В реальном режиме используется формат имён PyPI.
`--config` выбирает TOML-файл, `--help` показывает справку.

Программа выводит граф в формате `пакет: зависимости`. При ошибке
настроек, сети или метаданных завершает работу с кодом 1.
Функции `load_config` и `Config.describe` находятся в `src/config.py`,
`main` и `execute` в `src/cli.py`. `PyPIRepository.dependencies` получает зависимости,
`parse_requirement` разбирает записи Requires-Dist,
`applies` вычисляет условия окружения.

## Получение зависимостей

В реальном режиме программа читает `info.requires_dist` из JSON API PyPI
через стандартный `urllib.request`. Менеджеры пакетов, готовые библиотеки
сбора зависимостей и GitHub как источник данных не используются.
Кавычки, условия окружения и extras разбирает собственный код.
По умолчанию дополнительные группы отключены.

В тестовом режиме JSON задаёт прямые связи, например:

```json
{"A": ["B"], "B": []}
```

Граф строится DFS с явным стеком, без рекурсивных вызовов.
Циклы и повторные связи сохраняются, каждая пара «пакет, extras»
раскрывается один раз. Ограничения версий
сохраняются в требованиях, но программа не устанавливает пакеты
и не подбирает совместимый набор версий.

## Тестовые графы

```sh
python3 -B main.py --config configs/diamond.toml
python3 -B main.py --config configs/cycle.toml
python3 -B main.py --config configs/isolated.toml
```

`build_graph` и `format_graph` находятся в `src/graph.py`.
В тестах есть цепочка из 2001 вершины, цикл, петля, ромб
и дополнительные зависимости, пришедшие по разным путям.
В реальном режиме для каждой вершины читаются метаданные последней
версии. Это граф объявленных зависимостей, а не подбор версий для pip.

## Обратные зависимости

```sh
python3 -B main.py --config configs/demo.toml --reverse D
python3 -B main.py --config configs/cycle.toml --reverse B
```

`--reverse PACKAGE` ищет пакеты, зависящие от указанного прямо
или транзитивно. Без имени после `--reverse` целью становится пакет
из TOML. Рёбра результата направлены от цели к её предкам.

Для тестового репозитория рассматривается весь файл: будут найдены
и предки из других компонент исходного графа. В реальном режиме
поиск ограничен графом пакета из TOML, весь PyPI не сканируется.
`reverse_graph` разворачивает рёбра, `reverse_dependencies` повторно
использует DFS из третьего этапа.
