# Граф зависимостей Python-пакетов, вариант 4

Практическая работа № 2. ИКБО-62-25. Автор: xyezipster.
Этап 1: консольная программа с настройками в TOML.

Нужен Python 3.11+. Установка библиотек и сборка не требуются.
Запуск из папки проекта:

```sh
python3 -B main.py
python3 -B main.py --config configs/requests.toml
python3 -B -m unittest discover -s tests -v
```

В PyCharm можно открыть `main.py` и нажать Run.

## Настройки

```toml
package = "A"
repository = "data/demo.json"
test_mode = true
```

`package` задаёт имя пакета. `repository` содержит URL репозитория
или путь к тестовому JSON относительно TOML-файла. `test_mode`
переключает тестовый и реальный режимы. В тестовом режиме имена состоят
из больших букв A–Z. В реальном режиме используется формат имён PyPI.
`--config` выбирает TOML-файл, `--help` показывает справку.

На этом этапе программа проверяет настройки и выводит их в формате
ключ=значение. Ошибка параметра завершает её с кодом 1.
Функции `load_config` и `Config.describe` находятся в `src/config.py`,
`main` и `execute` в `src/cli.py`. Получение зависимостей появится
на следующем этапе.

Примеры неверных настроек находятся в `configs/errors/`.
